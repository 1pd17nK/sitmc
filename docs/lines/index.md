## 核心换乘枢纽推荐

### 1. 小各-东南前哨站（南域火车站）
* **可换乘线路**：前哨站环线（OLL）、南部联合线（SU）、海川线（OL）、河晏线（PL）
* **定位**：全网南域最重要的四线换乘总枢纽，连接下界环线与主世界两大核心主干。

### 2. SITMC 铁道建设公司总部站
* **可换乘线路**：前哨站环线（OLL）、海川线（OL）
* **定位**：公司总部所在地，兼顾企业办公与主世界-下界跨界通勤。

### 3. SITMC 铁道建设公司分部站
* **可换乘线路**：河晏线（PL）、橙圆线（SUESMC Line 11）、奶牛线（NENUMC Line 12）
* **定位**：跨服与高校联道计划的核心门户，承载对外交流与物资互通。

### 4. 茗柠の家
* **可换乘线路**：前哨站环线（OLL）、南部联合线（SU）、内环观光线（CCC）
* **定位**：下界内环枢纽，三线无缝换乘。
