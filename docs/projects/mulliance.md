# 联道计划 (MUlliance Cooperation)

**联道项目（MUlliance Cooperation，简称 MUC）** 是由 SITMC 铁道交通建设无限公司发起的高校生存服轨道互联互助倡议。

---

## 合作面向

SITMC 铁道交通建设无限公司 ➔ **MUA 各高校生存服**：

| 高校代号 | 当前合作阶段 | 合作对应线路 |
| :--- | :--- | :--- |
| **SUESMC** | 建设推进中 | [橙圆线 (SUESMC Line 11)](/lines/muc#1-橙圆线-tangerine-line-tl) |
| **NENUMC** | 正式通车运营 | [奶牛线 (NENUMC Line 12)](/lines/muc#2-奶牛线-klim-line-kl) |
| **DUT** | 待启动合作 | 规划方案研讨中 |
| **JSUMC** | 待启动合作 | 规划方案研讨中 |

---

## 合作原则与声明

::: warning ⚠️ 合作范畴声明
联道计划中联动双方为**非官方性质**的玩家社群友好合作，合作范围目前**仅限于 Minecraft 高校生存服**及玩家自建交通网络，不代表任何学校官方行政意志。
:::

### 核心倡议：
1. **标准互认**：推进线路编号体系、站台导视标识（中英对照与颜色编码）标准化。
2. **枢纽直联**：设立 SITMC 铁道建设公司分部为核心互换大厅，打通各服物资传输与交流壁垒。
3. **技术共享**：向合作伙伴开放红石自动发车系统、站台防爆结构及美学装饰方案。
