## 🚇 简介

SITMC 铁道交通建设无限公司是隶属于 **MUA-SITMC** 旗下的专业铁路交通工程组织，致力于在 Minecraft 服务器中规划、铺设、运营便民利民的铁道交通网络，并积极推进与 MUA 全国各大高校生存服的跨服“联道计划”（MUlliance Cooperation）。

## ✨ 网站功能特色

- **交互式线路大厅**：可视化展示 SITMC 本服 7 条骨干线路及 MUC 跨服联道线路，支持按线别筛选、站点中英文对照、换乘线路指示。
- **建设历史编年史**：从 2025.10 拓荒到 2026.01 正式建司及二期并网的历史时间线沉浸式回顾。
- **联道工程全览**：上海工程技术大学（SUESMC）、东北师范大学（NENUMC）等高校合作线路专题。
- **炫光美学界面**：采用定制 Railway 赛博霓虹动效，包含动态发光 Logo、发光背景环、玻璃拟态卡片等。

## 🛠️ 本地运行与构建

```bash
# 1. 安装依赖
pnpm install

# 2. 启动本地开发服务
pnpm run docs:dev

# 3. 构建静态站点
pnpm run docs:build

# 4. 预览静态输出
pnpm run docs:preview
```
